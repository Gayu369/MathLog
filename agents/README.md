# agents

This directory contains the "agents" for the MathLog project — small helper scripts and modules that perform automated tasks, experiments, or model-driven workflows used by the repository.

## What is here
- Source files for agent implementations
- Example configs and data needed to run agents
- Tests and helper scripts (if present)

## How to use
1. Inspect the files in this directory to see available agents and their README or docstrings.
2. Follow each agent's instructions (usually in comments or a companion file) to run or test locally.

Example (if an agent is a Python script):

```bash
python agents/example_agent.py --help
```

## Contributing
- Open a PR adding new agents or improving existing ones.
- Keep each agent self-contained with clear instructions and dependencies.

## Notes
Adding this README enables GitHub to display a folder-level README when browsing the `agents/` directory.
